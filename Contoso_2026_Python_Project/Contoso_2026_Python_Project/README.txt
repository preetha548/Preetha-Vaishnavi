CONTOSO 2026 - PYTHON PROJECT (NO MICROSOFT ACCESS)

Files:
- Geography.xlsx
- Stores.xlsx
- contoso_2026.py

Install:
    py -3.11 -m pip install pandas numpy matplotlib seaborn openpyxl

Run:
    py -3.11 contoso_2026.py

Output:
- Contoso_Output/Charts/
- Contoso_Output/Contoso_2026_Analysis_Report.xlsx

Important data note:
The supplied Contoso Geography and Stores workbooks contain source records whose
LoadDate/UpdateDate values are from 2008-2009. The project is named 2026, but
the underlying records have not been changed or fabricated to appear as 2026 data.
