BEST HOMEMADE HUMMUS WEBSITE

FILES
- index.html       Main webpage
- style.css        Responsive design and styling
- script.js        Serving-size selector and preparation checklists
- images/hummus.jpg  Recipe photo cropped from your supplied PDF

HOW TO RUN
1. Download and extract the ZIP file.
2. Open the hummus_recipe_website folder.
3. Double-click index.html to open it in Chrome or Microsoft Edge.
4. For editing, open the folder in Visual Studio Code.
5. Optional: install the VS Code extension "Live Server", right-click index.html,
   and choose "Open with Live Server".

NOTES
- No Python, PHP, database, or package installation is required.
- The recipe text and nutrition information follow the supplied PDF.
- The servings selector scales the measured ingredients. Salt and paprika remain
  "to taste", as in the supplied recipe.
- Google Fonts requires an internet connection; the page still works with fallback fonts.
