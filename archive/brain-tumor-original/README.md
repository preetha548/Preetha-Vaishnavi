# Original brain-tumor scripts

Byte-for-byte snapshots taken before repairs. Kept for learning-history and algorithm comparisons, not as supported launch entry points.

The original app has unsafe upload handling and debug mode. The original prediction script unpickles missing data and retrains during inference. Use the maintained root scripts and [project guide](../../ml/brain-tumor-classification/README.md) instead. Relative paths in these snapshots refer to the old root layout.
