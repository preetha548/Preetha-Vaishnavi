# Preserved historical artifacts

- `Projects.zip`: original project export, kept intact; contains additional projects and duplicate-looking material. Not a supported build entry point.
- `unused/`: unreferenced zero-byte root placeholders, preserved rather than deleted.
- `github-skills/`: original course workflows and step text. They are archived because their write-enabled automation could overwrite the portfolio README. They no longer execute from this directory.
- [Move manifest](MOVED_FILES.md): every original and destination path.

Archived workflows retain their original relative paths as historical text; they are not an active setup guide. Do not restore them to `.github/workflows` without reviewing their permissions and README mutations.
